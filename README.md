# 手部关键点检测与手势识别
基于昇腾Atlas200I DK A2开发板搭建的端侧手部关键点检测与手势识别项目。

## 项目简介
本项目依托Python与OpenCV实现摄像头实时视频流处理，将手部检测模型由ONNX格式通过ATC工具转换为适配昇腾NPU的OM离线模型，在开发板完成硬件加速推理。程序可识别手部21个关节关键点，根据关键点坐标距离、位置逻辑判定五种手势：OK、剪刀手、巴掌、拳头、竖大拇指，并实时绘制手部骨骼骨架，完整实现AI模型转换、嵌入式端视觉推理全流程。

## 开发环境
### 硬件环境
- 开发平台：Atlas 200I DK A2昇腾开发板
- 采集设备：USB摄像头
- 操作系统：Linux昇腾开发环境

### 软件依赖
Python 3.7及以上，opencv-python、numpy、昇腾ATC模型转换工具、MindX SDK推理工具

## 项目文件结构
```
hand-keypoint-recognition/
├── README.md               # 项目说明文档
├── hand.ipynb              # 项目主程序，集成推理与手势判定逻辑
├── landmark_det.ipynb      # 手部关键点检测独立程序
├── model/
│   ├── landmark.onnx       # 原始通用手部检测ONNX模型
│   └── landmark.om         # ATC转换完成、适配昇腾芯片的离线推理模型
```

## 核心功能流程
1. 视频采集与预处理：读取摄像头实时画面，完成图像缩放、归一化、通道转换；
2. 模型离线推理：加载landmark.om模型，NPU加速推理输出手部21个关键点坐标；
3. 骨骼绘制：预设关节连接索引，遍历关键点坐标连线绘制完整手部骨架；
4. 手势识别：依靠指尖、关节间欧氏距离与手指伸展逻辑，识别OK、剪刀手、巴掌、拳头、竖大拇指五种手势，画面实时输出识别结果。

## 项目运行步骤
1. 配置MindX SDK与ATC工具环境，安装Python第三方依赖；
2. 确认model目录存放landmark.onnx与转换后的landmark.om模型文件；
3. 打开hand.ipynb执行代码，程序自动调用摄像头；
4. 窗口实时展示标注关键点、骨骼连线与手势识别结果。

## 项目难点与优化方案
1. 模型格式适配：ONNX无法直接在昇腾硬件运行，使用ATC工具完成算子适配与硬件优化，生成OM离线模型；
2. 识别稳定性不足：光线差、手部遮挡时关键点偏移，优化图像预处理参数提升检测鲁棒性；
3. 程序容错性弱：新增摄像头、模型路径异常捕获逻辑，避免程序直接闪退。
